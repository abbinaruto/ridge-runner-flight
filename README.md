RIDGE RUNNER — Alpine Air Mail: an original flight game. Fly the Kestrel mail plane down three mountain valleys (dawn, noon, dusk), thread the golden rings, mind your fuel, and land on runway 09. Chase view over a winding valley with a river, pine forests, ridge silhouettes and a lit runway; full HUD with altitude, speed, heading compass, artificial horizon, fuel and throttle. Keyboard and mouse steering, procedural WebAudio engine and wind, three sorties with crosswinds and a dusk landing.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` from any static server. No build step, no network requests, no assets: every pixel and sound is drawn or synthesized in code.
